# Lumili 0.2 — обновление дизайна

## Обновить в StackBlitz
1. Останови запущенный сервер: нажми в Terminal и Ctrl+C.
2. Распакуй архив. Перетащи СОДЕРЖИМОЕ папки lumili в FILES своего проекта; подтверди замену. Обязательно загрузи папку assets с двумя PNG.
3. Нажми Save. В Terminal выполни npm ci.
4. Для браузера: npm run web.
5. Если профиль уже заполнен: вкладка Малыш → Посмотреть экран знакомства. Данные не удаляются.

## Открыть на телефоне через Expo Go
1. Установи/открой Expo Go. На iPhone войди в свой аккаунт Expo.
2. Останови веб-сервер в StackBlitz: Ctrl+C в Terminal.
3. Выполни npx expo login и войди в тот же аккаунт (пароль вводи только в терминале, не отправляй в чат).
4. Выполни npm run phone.
5. Если появился QR-код с адресом проекта, отсканируй камерой iPhone / сканером Expo Go на Android. Если предлагается development build, нажми s для переключения в Expo Go.
6. Держи StackBlitz открытым. Если QR нет, показан localhost/внутренний адрес или ошибка подключения — пришли скриншот терминала. Браузерный WebContainer не равнозначен локальному компьютеру; доступность внешнего адреса зависит от среды StackBlitz. Запуск на физическом телефоне пока не подтверждён.

Для обычного компьютера/серверной среды предусмотрен npm run phone:tunnel. В StackBlitz не устанавливай ngrok вслепую: его нативный исполняемый файл может не поддерживаться WebContainer.

SDK проекта 57. Версия Expo Go должна его поддерживать. При сообщении о несовместимости пришли точный текст — не меняй зависимости вручную.

## Что изменилось
- Светлый молочно-лавандовый фон, более лёгкие заголовки без засечек.
- Выбранный логотип-сердце и отдельная иллюстрация мамы с малышом.
- Давай познакомимся / Расскажи немного о себе и малыше / Продолжить.
- Дата вводится ДД.ММ.ГГГГ; прежние сохранённые даты остаются совместимыми.
- Компактные поля, прокрутка и поддержка клавиатуры.
- Повторный просмотр знакомства через вкладку Малыш.

## Что уже работает
Локальный профиль, редактируемый пример плана дня, отметки сна и кормлений, заметки и навыки. Пример плана не является медицинской рекомендацией. ИИ, сообщество, облачная синхронизация, системные уведомления и медицинские статьи пока не подключены. Проверка врачом не заявляется до её фактического проведения.

Данные сохраняются на устройстве; резервной копии пока нет. Текущие записи сохраняются при обновлении исходников в том же проекте, но другой адрес веб-приложения может иметь отдельное хранилище.
